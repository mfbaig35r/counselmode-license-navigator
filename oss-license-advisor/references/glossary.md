# Glossary

- **Open Source Definition (OSD):** OSI's 10 criteria (free redistribution, source code, derived works, no discrimination against persons or fields of endeavor, etc.). Licenses meeting it are OSI-approved.
- **Free software (Four Freedoms):** FSF definition: freedom to run, study/modify, redistribute, and distribute modified versions.
- **Copyleft:** Licensing that requires derivative works to be distributed under the same license.
- **Distribution / conveying:** Providing copies to third parties; the main trigger for GPL obligations.
- **Derivative / combined work:** A work based on the licensed program; scope is contested (linking, plugins).
- **Corresponding Source:** All source code needed to generate, install, and run the object code (GPLv3).
- **Installation Information:** Keys/methods needed to install modified software on a User Product (GPLv3 anti-tivoization).
- **SaaS loophole:** GPL obligations are not triggered when software is only run on servers; AGPL closes it.
- **License compatibility:** Whether code under two licenses can be combined and distributed in one work.
- **Proprietization:** Taking open code into closed-source products; allowed by permissive licenses, barred by copyleft.
- **Secondary License (MPL-2.0):** MPL option allowing combination with GPL-family licenses.
- **SPDX identifier:** Standard short license ID used in SBOMs and package metadata (spdx.org/licenses).
- **SBOM:** Software Bill of Materials listing components, versions, and licenses.
- **CLA / DCO:** Contributor License Agreement / Developer Certificate of Origin governing contributions.
- **Open-weight model:** Model whose weights are downloadable; not necessarily open source.
- **AUP:** Acceptable Use Policy restricting uses of a model.
- **Change Date (BUSL):** Date on which a BUSL-licensed version converts to its Change License.
- **OSI Open Source AI Definition 1.0:** OSI benchmark (Oct. 2024) for calling an AI system "open source": requires access to parameters, complete code, and sufficiently detailed data information. Not a license; moved from the Model Map in v2.2.
